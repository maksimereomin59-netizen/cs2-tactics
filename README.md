# CS2 Team Playbook

Рабочий инструмент капитана команды: тактики по картам, интерактивная схема поверх радара,
задачи и гранаты каждого игрока, видео разборов и чат команды.
Интерфейс — на русском, английскими остались только термины CS2 (смоук, экзекьют, AWP).

Стартовый набор: **Mirage, Ancient, Dust 2** — состав из пяти игроков, дефолтные расстановки
по сторонам и раскидки гранат. Всё это можно изменить или удалить.

## Вход

- **Название команды + PIN.** Без PIN тактики не видны.
- Новую команду создаёт **капитан**: название, PIN для игроков, своё имя и отдельный **PIN капитана**.
  Совпасть PIN команды и PIN капитана не даёт ни приложение, ни база: иначе любой игрок
  мог бы повысить себя до капитана.
- Игрок входит по PIN команды: смотрит тактики и видео, пишет в чат.
- Капитанский PIN включается в любой момент: **Настройки → Войти как капитан**.
- Профиль игрока выбирается один раз — устройство его запоминает (имя профиля становится
  именем автора в чате и в журнале).

## Разделы

Пять пунктов, ничего лишнего: **Обзор · Тактики · Игроки · Чат · Настройки**.

- **Обзор** — команда, капитан, блок «Что сделать сейчас» (задачи, гранаты и видео выбранного
  игрока; у капитана — быстрые действия) и список карт с количеством тактик.
- **Тактики** — витрина карт → тактики выбранной карты с фильтрами
  (сторона · тип · поиск по названию) → редактор тактики.
- **Игроки** — компактные карточки состава: номер, ник, роль, ближайшая тактика, кнопка
  «Открыть» и список видео. Внутри — карточка игрока со всем, что ему назначено.
- **Чат** — переписка команды. Капитан пишет объявления (отдельный тип сообщения,
  последнее объявление закреплено сверху ленты).
- **Настройки** — Команда, Игроки, Роли, Права, Язык, Аккаунт, Материалы и (капитану)
  Данные и синхронизация: подключение Supabase, проверка связи, экспорт и импорт.

## Редактор тактики

Главный экран приложения. Слева — инструменты, в центре — карта, справа — панель свойств
с тремя вкладками: **Элемент · Игрок · Тактика**. Сверху — быстрые действия.

Инструменты: выбор и перенос, двигать карту, игрок, противник, маршрут с точками остановки,
стрелка, линия, зона, точка, смоук, молотов, флешка, ХЕ, бомба, текст, ластик.
У каждого своя клавиша (`V H P X R A L Z O S M F G B T E`) и подсказка.

- **Отменить / повторить** — `Ctrl+Z` / `Ctrl+Shift+Z` (или `Ctrl+Y`), история на 60 шагов.
- **Сохранить** — `Ctrl+S`. Правки сначала живут черновиком на устройстве: карта не дёргается
  и не ждёт сеть на каждое движение. Сверху видно «Есть несохранённые правки»; при уходе
  с экрана черновик сохраняется сам.
- **Дубликат** — `Ctrl+D`, **удалить выбранное** — `Delete`, **снять выделение** — `Esc`.
- **Масштаб и панорама** — колесо, щипок двумя пальцами, кнопки `−/+`, «вписать карту»,
  `Пробел` — временный режим руки. Зум меняет только `transform` группы: DOM не перерисовывается.
- **Стрелка едет за игроком.** Конец стрелки или маршрута, оставленный рядом с токеном,
  примагничивается к нему: перетащил игрока — линия поехала следом.
- **Гнутая траектория.** У стрелки есть средняя ручка — тянешь и получаешь дугу
  (обход, флешка через балкон, ротация). «Два конца» — стрелка в обе стороны для разменов.
- **Расставить 1–5** кладёт состав по спауну стороны; **«Маршруты всех к точке»** — тап по
  точке, и от каждого игрока к ней идёт маршрут в его цвете.
- **Подписи токенов** листаются: номера → ники → ник и номер.
- **Сетка** включает линии и привязку к ним — удобно рисовать симметричные сплиты.
- **На весь экран** — карта во всё окно (шапка и меню прячутся, `Esc` возвращает).
- **Фокус на игроке** — чипы 1–5 над картой: всё чужое затемняется, в панели остаются
  его старт, маршрут, задача, гранаты, комментарий капитана и его видео.

Игрок без капитанского PIN схему только смотрит: можно приближать, двигать карту и
переключать игроков, инструментов правки нет.

### Телефон

Карта занимает максимум места: инструменты — нижняя панель (`Выбор · Игрок · Маршрут · Смоук ·
Текст · Ещё`), быстрые действия — полоса над картой, свойства — всплывающая шторка, которая
открывается тапом по элементу. Ничего не обрезается и не наезжает на системную панель.

## Видео

- Ссылка вставляется как есть: **YouTube** (обычная, `youtu.be`, Shorts, live) и **Vimeo**
  открываются встроенным плеером прямо в приложении — ухода на чужой сайт нет.
  Файлы `.mp4/.webm/.mov` играют через `<video>`, остальные ссылки открываются новой вкладкой.
- Видео привязывается к **игроку** и/или к **элементу схемы** (смоку, маршруту, токену)
  и получает тип: смоук, флешка, молотов, ХЕ, позиция, движение, другое.
- Капитан добавляет, переименовает, перепривязывает и удаляет видео; игрок видит только то,
  что относится к нему, — в панели «Игрок», в карточке игрока и в элементе схемы.

## Права

| | Капитан | Игрок |
|---|---|---|
| Тактики, карты, игроки, материалы, видео | создаёт, меняет, удаляет | смотрит |
| Схема | рисует и сохраняет | смотрит, приближает, переключает игроков |
| Чат | пишет, публикует объявления, удаляет любые сообщения | пишет, удаляет свои сообщения |
| PIN, состав, роли, экспорт/импорт, облако | да | нет |

Удаление настоящее: запись стирается из хранилища (локального или облачного), интерфейс
перерисовывается сразу, после перезагрузки удалённое не возвращается.

## Данные и синхронизация

- По умолчанию всё живёт в браузере устройства (`localStorage`) — работает офлайн.
- Облако — бесплатный **Supabase**: правки капитана приходят игрокам без перезагрузки
  (realtime), чат общий для всей команды. Настройка за 10 минут — [SETUP.md](SETUP.md).
- После заполнения `supabase-config.js` проверьте подключение:
  **Настройки → Данные и синхронизация → «Проверить связь»** — проверка по шагам скажет,
  что подключено, а что нет, и что сделать.
- **Экспорт** скачивает JSON-копию команды (PIN-хэши и соль в файл не попадают),
  **импорт** заменяет содержимое и сам перепривязывает тактики к картам, а задачи, гранаты
  и токены — к игрокам. Чат и журнал при импорте не трогаются.

## Запуск

Сборка и зависимости не нужны:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000` (на телефоне — адрес компьютера в той же сети).

## Проверки

```bash
cd tests
npm install
npm run all      # схема базы + клиентский слой + интерфейс целиком
```

Что pokryто: схема Supabase (таблицы, RLS, триггеры, realtime, storage) на настоящей
Postgres-совместимой базе PGlite; клиентский слой `db.js` на подставном Supabase-клиенте
(порядок строк, отправка и лимиты чата, офлайн, диагностика, защита ключей); интерфейс
в jsdom — от входа и создания команды до доски, видео, CRUD всех сущностей, прав игрока
и перезагрузки. Сейчас проходит **228 проверок: 28 (схема) + 53 (данные) + 147 (интерфейс)**.
Подробности — [tests/README.md](tests/README.md).

Проверки не покрывают настоящее облако Supabase и визуальную часть (браузер в окружении
разработки не устанавливался): подключение к своему проекту проверяйте кнопкой
«Проверить связь», а раскладку — на живом сервере в браузере.

## Структура

```text
index.html                 оболочка: шапка, навигация, экраны, шторки
styles.css                 дизайн-система и все экраны (мобильные и десктопные)
app.js                     экраны, маршруты, права, CRUD, чат, поиск
board.js                   тактическая доска: инструменты, жесты, история, панель свойств
ui.js                      примитивы интерфейса: иконки, кнопки, шторки, окна, тосты, видео
db.js                      данные: локальное хранилище + Supabase-адаптер + realtime
seed.js                    стартовый контент команды
data.js                    базовые тактики, зоны карт и гранаты для посева
supabase-schema.sql        схема облачной базы: таблицы, доступ, синхронизация
supabase-config.js         ключи проекта Supabase (заполнить по SETUP.md)
supabase-config.example.js тот же файл как образец
tests/                     проверки схемы, синхронизации и интерфейса
assets/maps/*.png          радары Mirage, Ancient и Dust 2
assets/maps/cards/*.jpg    обложки карт для витрины
assets/kabany-hero.jpg     постер команды — тихий фон экрана входа
manifest.webmanifest       PWA manifest
```
