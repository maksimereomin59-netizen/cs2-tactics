# 🎯 CS2 Плейбук команды

Мобильный сайт-шпаргалка для турнира по CS2: каждый игрок открывает сайт на телефоне,
нажимает на своё имя и видит **свою позицию на схеме карты, свои задачи и свои гранаты**
(стрелкой «откуда кидать → куда прилетит»). Без раскадровки по раундам — только то, что
нужно, чтобы быстро сориентироваться: дефолты по сторонам T/CT, базовые раскидки,
колл-ауты, план стороны, таймер раунда и эко-шпаргалка.

Карты в комплекте: **Mirage** и **Dust 2**.

## Как пользоваться

1. Открой сайт (локально или опубликованный — см. ниже).
2. Капитан жмёт ✏️ **«Режим капитана»**:
   - ники, роли, задачи, планы и тексты гранат правятся прямо тапом по тексту;
   - маркеры игроков перетаскиваются пальцем по схеме;
   - «+ добавить гранату» — новая раскидка (стрелка откуда→куда);
   - **Экспорт** — JSON со всеми правками (скинуть команде в чат), **Импорт** — загрузить его обратно.
3. Игроки просто открывают сайт → «Кто ты?» → своё имя → сторона T/CT → всё своё на одном экране.
4. Правки хранятся в телефоне (localStorage) и переживают перезагрузку; сайт работает офлайн
   (service worker) — на площадке без интернета тоже откроется.

Разделы:
- **Кто ты?** — карточка игрока: задачи, позиция на каждой карте, личные гранаты, памятки.
- **Карта** — вкладки: *Позиции* (кто где стоит), *Гранаты* (список + стрелки на схеме),
  *Колл-ауты* (тап по зоне = что это), *План* (5 пунктов на сторону).
- **Таймер** — раунд 1:55 / бомба 0:40, вибрация и звук на конце.
- **Эко-шпаргалка** — фулл-бай / форс / эко / сейв.

## Запуск локально

```bash
cd cs2-tactics
python3 -m http.server 8000
# открыть http://localhost:8000
```

(Любой статический сервер подойдёт — сборка не нужна.)

## Опубликовать для команды

- **GitHub Pages**: создай репозиторий, залей папку `cs2-tactics` (или весь этот репозиторий),
  включи Settings → Pages → ветка `main` / папка `/cs2-tactics`. Ссылку — в командный чат.
- **Netlify / Vercel / Cloudflare Pages**: drag-and-drop папки `cs2-tactics` — всё.
- Можно вообще без хостинга: сайт полностью статический, но для телефона удобнее ссылка.

## Структура

```
cs2-tactics/
├── index.html          оболочка
├── styles.css          тёмная «мобильная» тема
├── app.js              роутер, схемы карт (SVG), режим капитана, таймер, экспорт/импорт
├── data.js             ВСЁ содержимое: игроки, карты, зоны, позиции, гранаты, планы
├── sw.js               офлайн-кэш
├── manifest.webmanifest  установка на домашний экран как приложение
└── assets/icon.svg
```

Вся начинка — в `data.js`: координаты зон/маркеров в процентах от схемы, тексты — обычные
строки. Хочешь новую карту или шестого игрока — копируй блок и правь.

> Гранаты даны как базовые ориентиры («откуда → куда»): точные линии (куда целиться,
> джамп-сроу) докрутите на праке и впишите в «Режиме капитана» под себя.
