# CS2 Tactical Playbook

Строгий мобильный плейбук команды для **Mirage, Ancient и Dust 2**. Радар карты —
изображение, а позиции, маршруты и подписи рисуются отдельным SVG-слоем поверх него.

## Доступ

- **Закрытый доступ по командному паролю.** Без пароля тактики не видны.
- Первый запуск настраивает **капитан**: название команды, общий пароль для игроков,
  отдельный **PIN капитана** и стартовый экран игроков (задачи или карты).
- На одном устройстве может жить несколько команд: каждая входит по своему паролю
  и видит только свои тактики.
- **PIN капитана** открывает правки. Устройство капитана запоминается на **30 дней**.
- Игрок один раз выбирает свой профиль и сразу попадает на личные задачи и позиции.
  Сокомандников можно смотреть во вкладке «Команда».

## Что внутри

- три карты: Mirage, Ancient и Dust 2, стороны T / CT;
- карточки игроков, задачи, позиции, гранаты и планы;
- нижняя навигация: «Мои задачи» · «Карты» · «Команда»;
- кнопка **«Бомба 40»** в шапке сразу запускает таймер; рядом — время,
  «Стоп / Продолжить» и «Скрыть»;
- редактор доски: игроки-маркеры, стрелки, линии, рисунок от руки, номера и подписи;
- **колл-ауты только ручные**: капитан сам ставит текст, номера, линии и стрелки,
  автоматических зон и обводок нет;
- компактная панель редактора без горизонтального скролла, кнопки
  «Шаг назад» и «Удалить» закреплены и всегда видны, как и кнопка «Назад».

## Капитан

- Кнопка «Капитан» в шапке → ввод PIN (или сразу, если устройство запомнено).
- Настройки: название, первый экран игроков, смена пароля и PIN,
  смена команды, сброс тактик, удаление команды.
- Экспорт: файл команды отправляется игрокам (в мессенджер). Игроки жмут
  «Импорт от капитана», вводят командный пароль — и видят тактики капитана.
- Сами пароли в файл не входят — только проверочные хеши.

## Запуск

Сборка и зависимости не нужны:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000` (на телефоне — адрес компьютера в той же сети).

## Структура

```text
index.html                 оболочка: шапка с бомбой, низ-навигация, ворота входа
styles.css                 строгий мобильный интерфейс
app.js                     команды и доступ, профили, редактор, таймер бомбы
data.js                    базовые игроки, планы, позиции и гранаты
assets/maps/*.png          радары Mirage, Ancient и Dust 2
sw.js                      удаление кэша прежних версий
manifest.webmanifest       PWA manifest
```
