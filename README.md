# CS2 Tactical Playbook

Командный плейбук для **Mirage, Ancient и Dust 2**: тактики по картам и сторонам,
схемы с маркерами поверх радара, задачи игроков, гранаты и материалы.

## Вход

- **Название команды + PIN.** Без PIN тактики не видны.
- Новую команду создаёт **капитан**: название команды, PIN для игроков,
  своё имя и отдельный **PIN капитана**.
- Капитанский PIN открывает панель управления и все правки.
- Игрок один раз выбирает свой профиль — устройство его запоминает.

## Разделы

- **Обзор** — команда, состав, избранное, недавние изменения.
- **Карты** — Mirage / Ancient / Dust 2, тактики T и CT по каждой.
- **Тактики** — список с фильтрами по карте и стороне.
- **Игроки** — состав, карточки, личные задачи и гранаты.
- **Материалы** — файлы и ссылки команды.
- **Управление** (капитан) — команда, PIN, шаблоны, экспорт/импорт.

## Капитан

- Создаёт карты, тактики, игроков и материалы.
- Редактирует тактики блоками: текст, задачи, гранаты, схема, файлы.
- Схема: маркеры игроков, стрелки, линии, подписи поверх радара.
- Дублирует тактики, сохраняет шаблоны, меняет PIN команды.
- Экспорт: JSON-копия всей команды (пароли в файл не входят).

## Синхронизация

- По умолчанию данные живут в браузере устройства (офлайн-копия).
- Облачная синхронизация между устройствами — через бесплатный Supabase:
  правки капитана появляются у игроков сами, без перезагрузки.
  Настройка за 10 минут — см. [SETUP.md](SETUP.md).
- После настройки заполните `supabase-config.js` (Project URL и anon public key)
  и проверьте соединение в приложении: **Управление → Облако → «Проверить связь»** —
  проверка по шагам скажет, что подключено, а что нет.

## Запуск

Сборка и зависимости не нужны:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000` (на телефоне — адрес компьютера в той же сети).

## Структура

```text
index.html                 оболочка: шапка, навигация, экраны входа
styles.css                 мобильный интерфейс панели
app.js                     экраны, редактор блоков, схемы, поиск
db.js                      данные: локальное хранилище + Supabase-адаптер
seed.js                    стартовый контент команды
data.js                    базовые тактики и гранаты для посева
supabase-schema.sql        схема облачной базы: таблицы, доступ, синхронизация
supabase-config.js         ключи проекта Supabase (заполнить по SETUP.md)
supabase-config.example.js тот же файл как образец
tests/                     проверки схемы, синхронизации и интерфейса (см. tests/README.md)
assets/maps/*.png          радары Mirage, Ancient и Dust 2
sw.js                      удаление кэша прежних версий
manifest.webmanifest       PWA manifest
```
