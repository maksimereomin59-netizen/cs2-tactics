# CS2 Tactical Playbook

Статический мобильный плейбук команды для **Mirage, Ancient и Dust 2**. Основой каждой тактической доски служит полноценный радар карты, а позиции, маршруты и подписи рисуются отдельным SVG-слоем прямо поверх него.

## Что доступно

- три основные карты: Mirage, Ancient и Dust 2;
- отдельные планы и пометки для сторон T / CT;
- маркеры пяти игроков в виде номеров в обводке или ников;
- перетаскивание позиций игроков по радару;
- цветные стрелки, прямые линии и свободное рисование;
- произвольные цифровые метки и текстовые подписи;
- выбор, перемещение, перекраска, переименование и удаление объектов;
- карточки игроков, задачи, гранаты, колл-ауты и планы;
- отдельный ненавязчивый таймер установленной бомбы на 40 секунд;
- экспорт и импорт плейбука в JSON;
- офлайн-режим через service worker.

Отсчёта времени раунда в приложении нет.

## Режим капитана

Нажмите **«КАПИТАН · ВХОД»**. При первом входе приложение предложит установить пароль. В дальнейшем любое новое открытие режима правок требует этот пароль. После разблокировки на тактической доске появляется панель инструментов.

Пароль хранится только на текущем устройстве в виде хеша и не включается в экспорт. Само приложение полностью статическое: изменения и настройка доступа находятся в `localStorage` конкретного браузера. Для передачи готовой схемы на другое устройство используйте экспорт / импорт.

## Запуск

Сборка и зависимости не нужны:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.

## Структура

```text
index.html                 оболочка приложения
styles.css                 строгий адаптивный интерфейс
app.js                     роутер, редактор доски, пароль и bomb timer
data.js                    игроки, планы, позиции и гранаты
assets/maps/*.png          радары Mirage, Ancient и Dust 2
sw.js                      офлайн-кэш
manifest.webmanifest       PWA manifest
```
