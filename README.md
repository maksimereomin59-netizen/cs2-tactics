# CS2 Tactical Playbook

Командный плейбук для **Mirage, Ancient и Dust 2**: тактики по картам и сторонам,
схемы с маркерами поверх радара, задачи игроков, гранаты и материалы.

## Вход

- **Название команды + PIN.** Без PIN тактики не видны.
- Экран входа — постер команды (`assets/kabany-hero.*`): он анимирован (медленное «дыхание», свет,
  параллакс за курсором/наклоном телефона), а меню входа стоит поверх него в тёмном стекле (блюр + затемнение).
  Тот же постер слегка размыт на всех рабочих страницах приложения.
  Капитан ставит общее фото команды, игрок может поставить своё — ползунки блюра и затемнения рядом.
- Новую команду создаёт **капитан**: название команды, PIN для игроков,
  своё имя и отдельный **PIN капитана**.
- Капитанский PIN открывает панель управления и все правки.
- Игрок один раз выбирает свой профиль — устройство его запоминает.

## Разделы

- **Обзор** — команда, состав, избранное, недавние изменения.
- **Карты** — витрина крупных фото-карточек карт; внутри тактики T и CT и материалы карты.
- **Тактики** — сначала выбор карты крупной карточкой с фото, затем тактики выбранной карты
  с фильтрами по стороне и типу.
- **Чат** — внутрибраузерная переписка команды; капитан публикует объявления (пин-баннер сверху).
- **Игроки** — состав, карточки, личные задачи и гранаты.
- **Материалы** — файлы и ссылки команды.
- **Управление** (капитан) — команда, PIN, шаблоны, экспорт/импорт, сброс содержимого.

## Капитан

- Создаёт карты, тактики, игроков и материалы.
- Ставит карте своё фото-обложку (карточка карты и герой-полоса), иначе берётся встроенная
  размытая обложка карты с названием.
- Сбрасывает содержимое команды (Управление → «Сброс содержимого»): тактики, материалы, шаблоны,
  чат и журнал удаляются, карты с фото остаются — можно рисовать с нуля.
- Редактирует тактики блоками: текст, задачи, гранаты, схема, файлы.
- Схема: рисует прямо по радару — стрелки движения (можно гнуть), линии, зоны, карандаш,
  токены игроков, номера, подписи и гранаты; отмена/вернуть, удаление, дубликаты, сетка
  с привязкой, полный экран. Подробности — ниже.
- Дублирует тактики, сохраняет шаблоны, меняет PIN команды, ставит общее фото на экран входа.
- Экспорт: JSON-копия всей команды (пароли в файл не входят).

## Схема: рисование движения

Инструменты (у каждого своя клавиша, когда доска в фокусе):
`V` выбор · `A` стрелка движения · `L` линия · `P` карандаш · `Z` зона ·
`1` игрок · `N` номер · `T` текст · `G` граната · `E` ластик. Плюс `Ctrl+Z` / `Ctrl+Shift+Z` —
отменить/вернуть, `Ctrl+D` — дубликат, `Delete` — убрать выбранное, `Esc` — снять выделение
(или выйти из полноэкранной схемы).

- **Стрелка едет за игроком.** Конец стрелки, оставленный рядом с токеном игрока,
  «примагничивается» к нему: перетащил игрока — маршрут поехал следом.
- **Гнутая траектория.** Выбери стрелку и тяни жёлтый маркер посередине — получится дуга
  (обход, флешка через балкон, ротация). `⇄ Два конца` — стрелка в обе стороны для разменов.
- **Быстрые кнопки.** «Расставить 1–5» кладёт состав по спауну стороны (T или CT),
  «Стрелки к точке» — тап по точке, и от каждого игрока туда идёт свой маршрут в его цвете.
- **Номера и ники.** Кнопка с иконкой метки листает режимы подписи токенов: `Номера` → `Ники` → `Ник+№`.
- **Пунктир и толщина** — для второстепенных маршрутов (что не основной экзекьют).
- **Сетка** включает линии и привязку к ним — удобно рисовать симметричные сплиты.
- **Во весь экран** — большая схема прямо на телефоне: рисовать и править можно там же.

Рисование не лагает: правки схемы сначала живут черновиком на устройстве, а уходят в облако
кнопкой «Сохранить» на панели схемы (или автоматически при выходе с экрана). Игрок без
капитанского PIN схему только смотрит (можно развернуть на весь экран); сохранённые правки
игроки видят без перезагрузки.

## Синхронизация

- По умолчанию данные живут в браузере устройства (офлайн-копия).
- Облачная синхронизация между устройствами — через бесплатный Supabase:
  правки капитана появляются у игроков сами, без перезагрузки.
  Настройка за 10 минут — см. [SETUP.md](SETUP.md).
- После настройки заполните `supabase-config.js` (Project URL и anon public key)
  и проверьте соединение в приложении: **Управление → Облако → «Проверить связь»** —
  проверка по шагам скажет, что подключено, а что нет.

## Запуск

Сборка и зависимости не нужны:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000` (на телефоне — адрес компьютера в той же сети).

```text
assets/maps/*.png          радары Mirage, Ancient и Dust 2

assets/kabany.jpg          прежнее фото команды (запасное, можно заменить своим)
sw.js                      удаление кэша прежних версий

```
